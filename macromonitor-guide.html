一、这个网站是干什么的 定位

一句话：它是一个 美国宏观经济"体温计" + "雷达"。 它把美联储、市场利率、资产价格、就业、通胀、信用风险等几十个指标，实时汇总成你能一眼看懂的状态判断。

你不用会经济学。你只需要学会看三样东西：当前值、变化方向、信号颜色。网站已经把"专家怎么解读"这件事做成了自动信号，你读信号即可。

核心心法：宏观是"慢变量"。这个网站不是用来做短线交易的，而是帮你看清——市场在"冒险"还是"避险"？经济在"扩张"还是"走向衰退"？钱是"变多"还是"变紧"？每天花 5 分钟看趋势，比盯单日跳动有用得多。

二、先搞懂 5 个基础概念 入门

1. 状态区间（Regime）

网站给每个板块一个"当前状态"判断，常用两类词：

  • risk-on / bullish（乐观 / 健康）：市场愿意承担风险，或数据偏暖。
  • risk-off / bearish（避险 / 压力）：市场在防御，或数据偏冷/偏险。
  • mixed（胶着 / 分化）：信号互相打架，看不清方向。

记住：这是"当前状态"，不是"预测"。它告诉你现在在哪，不保证明天去哪。

2. 收益率曲线与利差（最该懂的一个）

"收益率"就是借钱要付的利息。短期（如 2 年）和长期（如 10 年）利率之间的差，叫利差。

  • 正常：长期利率 > 短期利率（曲线向上）。
  • 倒挂（利差 < 0）：短期反而比长期贵。历史上，收益率曲线倒挂是预测衰退最可靠的先行信号之一，通常领先衰退 12–18 个月。
网站里你会反复看到 10Y-2Y 利差 和更可靠的 3M-10Y 利差。只要它为负，就是一盏"黄/红灯"。

3. 流动性（市场里的"钱"够不够）

流动性 = 金融系统里可随时动用的钱。关键角色：

  • 美联储资产负债表（WALCL）：美联储"印/缩"的钱。在缩表（QT）就是在抽水。
  • RRP（逆回购）：货币基金存在美联储的钱，曾是"缓冲垫"，现已基本耗尽。
  • TGA（财政部现金账户）：财政部存在美联储的钱。TGA 上升 = 从市场抽水。
  • SOFR-IORB 利差：融资利率减准备金利率。它由负转正，是"钱开始紧张"的第一道确认信号。

4. 衰退先行指标（不等衰退来了才看）

"先行"= 比衰退本身早发生。网站用一组领先指标当雷达：收益率曲线倒挂、Sahm 规则（失业率）、初请失业金、纽约联储衰退概率、金融压力指数。它们亮红灯，往往比官方宣布衰退早大半年。

5. 信用利差（谁还敢借钱）

高风险企业债（HY）相对国债要多付的利息。利差走阔 = 投资者担心违约、要求更高补偿 = 避险情绪升温；收窄 = 一切安好。

三、推荐阅读顺序 导航

页面板块虽多，但有逻辑顺序：先看全局 → 再看"现象"（资产/波动）→ 找"原因"（利率/美联储/流动性/经济/信用）→ 最后看"前瞻雷达"（衰退/总览）。

① 全局状态 + 分析总览一眼看全盘风险分和状态
② 大类资产 / 波动率钱正在往哪去、市场慌不慌
③ 利率 / 美联储 / 流动性定价之锚、央行在干嘛、钱够不够
④ 经济 / 信用基本面与违约风险是否恶化
⑤ 衰退信号最前瞻的衰退雷达（红黄绿灯）
⑥ 加密货币风险偏好的"边缘"温度计
新人最简路径：每天只看 分析总览的分数 + 衰退信号的灯 + 收益率曲线是否倒挂，就抓住了 80% 的信息。

四、逐板块解读 正文

🌐 全局状态（globalRegime）

看什么：一个总的 market regime 判断（risk-on / risk-off / mixed），由收益率曲线、VIX、金融压力、信用分位等合成。

背后含义：市场整体的"体温"。risk-off 不预示立刻崩盘，只是说防御情绪占上风。

新人盯：它的 signal 从 risk-on 翻成 mixed/risk-off 时，就要开始留意下面细分板块了。

📊 分析总览（riskScore）

看什么：0–100 的加权风险总分 + 风险等级（低/中/高）+ 7 个因子条（流动性、衰退、利率、经济、信用、波动率、跨资产）。

背后含义：把 7 个板块按权重（流动性 18%、衰退 17%、利率 15%、经济 14%、信用 14%、波动率 12%、资产 10%）合成一个总分。条越长越红 = 该板块压力越大。

新人盯：先看总分和等级，再看哪几根条变红——红的板块就是当下主要矛盾。

💹 大类资产（assets）

看什么：纳指(NDX)、WTI 原油、布伦特原油、黄金、铜等的实时价格和周/月涨跌（带方向箭头）。

背后含义：钱在往哪去。金涨、铜跌常暗示避险/担忧增长；油价受供需与地缘影响。

新人盯：别只看价格，看 ▲/▼ 周变化。WTI/Brent 用的是 Yahoo 实时价，其余资产也多为实时源。

🌊 波动率（volatility）

看什么：VIX（美股恐慌指数）、OVX（原油波动率）、GVZ（黄金波动率），以及"处于压力区的资产数量"。

背后含义：市场慌不慌。VIX > 20 一般被视为紧张，> 30 是明显恐慌。

新人盯：VIX 是"市场情绪温度计"，它飙升往往和下跌同时发生，是用来确认风险偏好的最好指标之一。

📉 利率（rates）

看什么：10 年期、2 年期国债收益率、TIPS（实际利率）、BEI（通胀预期），以及曲线形态。

背后含义：这是所有资产定价的"锚"。长端利率涨 = 融资环境收紧；曲线倒挂 = 衰退预警（见概念 2）。

新人盯：重点看 10Y-2Y 利差 是否为负；BEI 上升代表市场担心的通胀在抬头。

🏛️ 美联储（fed）

看什么：政策利率区间、市场隐含的降息/加息路径（看短端利率）、缩表进度（WALCL/RRP/TGA），以及官员"鸽鹰评分"。

背后含义：央行在"放水"还是"收水"。鸽 = 偏宽松（利好风险资产），鹰 = 偏收紧。

新人盯：官员评分是"展示性模型值"（基于 2Y 利率自动算，非官方评分），别当成美联储内部真实立场；真正该看的是政策利率和缩表速度。

💧 流动性（liquidity）

看什么：净流动性、美联储总资产、RRP、TGA、银行准备金、SOFR-IORB，以及 LPI（流动性压力指数，含三子维度）。

背后含义：市场里的"钱"是变多还是变少。RRP 耗尽 + TGA 上升 + SOFR-IORB 转正 = 流动性从"有缓冲"进入"无缓冲"的压力阶段（类比 2019 年回购危机前夜）。

新人盯：把 SOFR-IORB 和 LPI 分数 当核心。SOFR-IORB 转正是第一警报；LPI 越高流动性压力越大。

🏗️ 经济（economy）

看什么：GDP（环比/同比）、失业率、CPI（通胀）、Sahm 规则等。

背后含义：基本面是否健康。失业率上升、GDP 转负 = 经济走弱。

新人盯：失业率与 Sahm 规则——失业率一旦较快上行，往往是衰退临近的确认。

🏦 信用（credit）

看什么：高收益债利差（HY OAS）、金融状况指数（NFCI）、CCC/IG 评级利差。

背后含义：违约风险与融资环境。HY OAS 走阔 = 企业借钱更难更贵 = 避险。

新人盯：HY OAS 的"分位"——处于历史高位时分位，说明信用环境已偏紧。

🚨 衰退信号（recession）

看什么：6 盏红绿灯：10Y-2Y 利差、3M-10Y 利差、Sahm 规则、纽约联储衰退概率、初请失业金(4 周均)、圣路易斯金融压力。外加综合评分/等级。

背后含义：这是全站最"前瞻"的衰退雷达。每盏灯：triggered 红 已触发、warning 黄 逼近阈值、safe 绿 正常。

新人盯：综合评分 > 60 = 高风险。灯从绿变黄就要警惕，变红说明该指标已进入历史危险区。

🪙 加密货币（crypto）

看什么：BTC 周涨跌、ETF 资金流、ETH/BTC 比。

背后含义：加密是风险偏好的"边缘"指标——它涨通常代表资金敢冒险，跌代表避险。

新人盯：把它当"温度计的末梢"，不必深究，看方向即可。

五、颜色与标签速查表 速查

你看到的含义新人怎么读
risk-on / bullish偏乐观 / 健康可以松口气，但别忽视风险
risk-off / bearish偏避险 / 压力开始警惕，去看细分板块哪出问题
mixed信号分化 / 胶着方向不清，看周/月趋势而非单日
triggered（红）衰退指标已触发该指标进入历史危险区
warning（黄）逼近阈值未触发预警，值得关注
safe（绿）正常暂无警报
unknown（灰）数据缺失不是没风险，是没数据，别误读为安全
关于"涨/跌"颜色的重要提醒：宏观里"涨"不等于"好"。例如 VIX 涨 = 市场更慌（坏），失业率涨 = 就业变差（坏），收益率涨 = 融资收紧（视情况）。所以本站的箭头只表示数值方向，而颜色表达的是"信号含义"（压力红 / 健康绿）。别把"红了"简单等同于"跌了"。

六、给新人的 6 条实操建议 心法

  1. 每天先看"分析总览"分数，再看哪几根因子条变红——红的板块就是今天的主矛盾。
  2. 盯 3 个最常亮的"红灯"：收益率曲线倒挂、Sahm 规则、SOFR-IORB 转正。这三者是衰退/流动性压力的最早警报。
  3. 看周/月变化，别被单日跳动吓到。宏观是慢变量，一天涨跌常是噪音。
  4. "预计 / estimated"标注 = 推算值，不是官方公布值，可信度略低，别当确定结论。
  5. 灰色 unknown ≠ 安全。它只是数据缺失，别误读。
  6. 把它当"观察哨"而非"预测机"。网站告诉你"现在在哪、风险在哪"，不保证"明天一定怎样"。结合新闻一起看最稳。
